## Acceptance criteria

- [ ] 用户交付物含签名可安装 APK、版本/哈希、安装及配置说明；正常使用只要求 Android 权限、互联网与供应商 Key，文档不要求服务器、SSH、设备桥或开发工具。Key 不包含在产物和报告中；测试只向用户配置的模型端点发送请求。

- [ ] 从最终集成 SHA 构建并安装 APK，在无 env 注入、无桥地址/Token 的安装中经 App 设置模型 Key 与系统权限；停止全部项目服务、关闭无线调试并拔掉 USB 后完成任务及恢复检查。较早的桥接或仅 VLM APK 证据不能替代。
- [ ] 分别保留原版双入口、提取后参考后端、旧桥接 App+VLM、独立 App+VLM、加 Jev 选择、加树核验、加按需规划的版本化结果；所有失败和费用纳入。
- [ ] 按已冻结标准运行最终中文任务/留出集并做用户复核，未验证范围明确列出；不虚构收益。
- [ ] 统一最终使用、暂停/取消/恢复、配置与更新说明，任务关闭有提交、命令、环境、报告与剩余限制。
