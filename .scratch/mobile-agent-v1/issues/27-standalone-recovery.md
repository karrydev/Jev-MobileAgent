## Acceptance criteria

- [ ] 手机本地记录能重建任务、观察/动作身份、执行前意图、回执、模型请求与费用/步数；恢复不重置预算。执行前后记录顺序可判定 NOT_EXECUTED/EXECUTED/UNKNOWN；进程终止窗口无法证明的结果保持 UNKNOWN。
- [ ] 真实演练派发前、执行后回执持久化前、回执后核验前中断，并核对手机副作用；至少包含 App/执行服务进程重启、手机重启、模型网络中断和权限撤销。测试注入点明确标注，不用服务端重启代替手机内验证。
- [ ] 重启、解锁、网络恢复或重新授权不会自动续跑。核对时重新观察，用户确认前再次采集；目标或现场变化使原确认失效。已完成目标不重复执行；人工完成目标与 Agent 执行记录分别归因。
- [ ] 暂停/取消后的旧任务代次、迟到模型响应和失效观察不能派发；无法确定动作结果时暂停并解释缺口。取消后已知未执行可释放任务占用，不绕过未知结果；暂停不能撤销已发生动作。
- [ ] 普通使用和恢复无需连接桥、提供 Token 或读取开发机文件。无 USB、无线调试、ADB reverse 和项目编排服务时完成恢复演练；本机证据在测试后导出。若某 ROM 的强制停止关闭无障碍，按系统授权恢复并保留该限制。
