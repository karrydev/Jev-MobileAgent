# 01 — 一个模拟任务从提交到独立判定完成

**What to build:** 开发者从公开任务入口提交一个固定目标，服务端通过实际本地传输连接模拟设备，观察、执行一个动作并重新观察，返回任务状态与可核对的最小轨迹。

## Acceptance criteria

- [ ] 提供可重复的启动与运行方式；使用合成页面状态判定完成，动作回执成功而页面未变化的反例必须失败。
- [ ] 最小协议附正常/非法样例、版本与消费者检查；任务、观察、动作、回执、核验可关联，明确一个任务与一个在途动作。
- [ ] 连接具备最小认证与设备身份校验；错误身份和不兼容版本明确拒绝。建立后续 App 与服务可复用的入口。
- [ ] 确定本切片所需工程布局、传输、配置和依赖检查；未来恢复/截图字段按后续切片扩展，模拟模式显式标注。

## 范围与协调

任务入口、最小服务、模拟设备和共享契约；协调者负责根构建与接口。

## 交付证据

记录最终合入 SHA、验证命令、契约与环境版本、实际结果和未验证项。模拟证据只关闭模拟任务；真实能力缺失时不能记为通过。共享接口变更由集成负责人串行合入。
