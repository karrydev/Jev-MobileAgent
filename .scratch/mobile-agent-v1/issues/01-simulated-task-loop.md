- [x] 提供可重复的启动与运行方式；使用合成页面状态判定完成，动作回执成功而页面未变化的反例必须失败。

- [x] 连接具备最小认证与设备身份校验；错误身份和不兼容版本明确拒绝。建立后续 App 与服务可复用的入口。
