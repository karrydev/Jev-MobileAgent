## Acceptance criteria

- [ ] 每个样例有初始状态、输入、真值来源、终局判据；动作成功但任务未完成、动作无效、加载和证据缺失均有反例。
- [ ] 输出稳定的判分结果；决策样例中无答案、未来帧或后台真值；开发/留出按任务或轨迹划分。
- [ ] 冻结首轮任务、重复次数、预算、回归允许值和放行规则的版本化模板，并给出待真实验证的建议值；不把它们标成用户已批准。
- [ ] 只使用本切片自有任务/判分输入格式，不修改尚未合入的运行协议；后续由证据贯通任务适配。

## 范围与协调

独立评测入口、合成样例与判分规则，可与任务 01 并行。

## 交付证据

记录最终合入 SHA、验证命令、契约与环境版本、实际结果和未验证项。模拟证据只关闭模拟任务；真实能力缺失时不能记为通过。共享接口变更由集成负责人串行合入。
