## Acceptance criteria

- [x] 每个样例有初始状态、输入、真值来源、终局判据；动作成功但任务未完成、动作无效、加载和证据缺失均有反例。
- [x] 输出稳定的判分结果；决策样例中无答案、未来帧或后台真值；开发/留出按任务或轨迹划分。
- [x] 冻结首轮任务、重复次数、预算、回归允许值和放行规则的版本化模板，并给出待真实验证的建议值；不把它们标成用户已批准。
- [x] 只使用本切片自有任务/判分输入格式，不修改尚未合入的运行协议；后续由证据贯通任务适配。
