# 任务 22：手机内 Jev 影子验证计划

2026-09-25，真实调用前冻结任务与次数；实现及候选策略的 SHA 在开发集检查后、首次留出调用前补记。模型 `jev-1.13.0`，App 直接请求配置的 HTTPS endpoint；不使用 Python 代理或宿主决策。凭据仅经 App 设置；公开报告不含 Key、个人页面和原始敏感响应。

## 顺序与范围

1. Android 客户端先做最小中文 choice 协议探针（1 次有效请求、1 次显式非法协议请求）；21 的宿主探针只作协议来源，不能代替手机客户端实测。停止自动重试。
2. 复用 11 的开发样本语义检查候选、中文已知输入、缺参、非法 ID 和错误选择分类；回放负例不为制造错误而反复调用真实模型。
3. 在冻结的候选规则和阈值上运行留出：旧样本的过期/空候选应本地回退，不请求模型；增加四个独立合成任务（暂停音乐、切换已完成标签、保留草稿返回、输入明确城市文本），各调用一次。具体节点/候选与独立可接受 ID 在请求前固定并散列。决策输入不含真值/未来帧/正确 ID；不依据留出结果调参后重写本轮分数。
4. 真机中文输入与视觉蓝框各跑一次 shadow-on，与 26 独立 VLM 基线对照。VLM 仍执行；Jev 建议只记报告。记录没有正确候选、选择错误、合法等价动作、无效/低置信/错误回退及与 VLM 动作差异。真实页面副作用由主 Agent 核对，不用 VLM 选择充当正确标签。

每个任务保留 26 的 5 步 / 25 次 VLM 请求 / 单任务 ¥1 限制；每个决策边界最多一个 Jev 请求，无自动重试。首批真实 Jev 总请求不超过 20，每次预留 ¥0.01；两次 VLM 任务各预留 ¥1，仍受用户全程 ¥10 预算限制。Jev USD usage/文档费率和保守 CNY 预留分别记录，不虚构实时汇率或账户账单。预留用尽即停止，不为通过而无限重跑。

失败完整留证；只有具体修复或环境改变才允许新增尝试。影子结果不证明 Jev 控制后的任务成功率，也不提前宣称降本。此票不重复要求用户拔线，26 已验证同一手机本地运行边界；最终组合与恢复的拔线门槛分别由 28/27 验收。测试后锁屏。
