# 任务 23 受控选择配对验证

冻结日期：2026-09-25；首次真实调用之前建立。实现基线 f2037ca；最终实现 SHA/APK 散列随运行记录填写。本轮只改变选择策略，Manager 与 Reflector 的频率及终局判据保持不变。

## 样例与条件

同一最终 APK、OnePlus 8T / Android 14、GUI-Plus gui-plus-2026-02-26、TypeSafe jev-1.13.0；App 中已有加密配置。每个场景先仅 VLM，再启用 Jev 选择，各一次，不自动重试；影子开关关闭。每次重新进入受控页面并复位场景，开始前输入框为空、蓝框未点击，软键盘收起、竖屏。两种模式使用相同目标、初始页面、5 步/25 VLM 请求/¥1 每任务限制，Jev 共用累计请求和费用门控，不重置任何账本。

| 场景 | 目标 | 独立判据 |
|---|---|---|
| 中文输入 | 在中文输入框中输入“独立手机测试成功” | 新观察中的输入框文本精确相等，App 正确结束；Jev-on 至少一个实际派发动作来源为合法 Jev 候选 |
| 自绘视觉目标 | 沿用受控页“视觉手势目标”生成的蓝框点击目标 | 自绘蓝框可见完成标志及本地独立判据成立；Jev-on 不执行错误的预设按钮，候选缺失明确回退视觉 |

## 放行规则

四次运行均保存全部模型请求、动作来源、回执、独立结果、错误和回退、时长与费用。两种模式每个场景都成功，且 Jev-on 中文任务确实执行过 Jev 候选，自绘蓝框未误选预设按钮，才通过本轮受控放行。任何失败保留，先分类并修复；只有具体代码或环境变化才能开启另一个编号的尝试，不能替换原记录。未达标保持策略默认关闭，不声称通过或降低标准。样本只证明受控行为，不宣称统计收益或任意跨 App 成功率。

离线针对非法 ID、过期观察、取消后的迟到响应、缺参/空候选、视觉缺失反例和预算拒绝进行受影响验证；不重复任务22整套探针。审查包括复用的候选/比较修复必要范围。

## 预算与设备

累计用户限额 ¥10。每次真实任务前，在 live-model-budget.json 预留 ¥1（包含最多5次 Jev 请求的 ¥0.05 保守占用），完成后按 VLM usage 结算，Jev 保留独立 CNY 预算占用及未知实际费用；不虚构 USD/CNY 汇率。首批最多四个任务、Jev 最多9个新增请求（现累计11，硬门控20）；若剩余次数不足，中止新请求并记录，不清空计数绕过门控。

主 Agent 独占真机、真实 API 和凭据。USB 本轮仅供准备与取证，任务运行不依赖宿主服务；本轮不冒称拔线证据。最终拔线及恢复在27/28集中验收。每次结束、异常或开发等待均取消仍活动的测试任务后锁屏，并检查 Dozing/Asleep。原始观察与图片留本机私有目录，公开证据仅保留脱敏事实。
