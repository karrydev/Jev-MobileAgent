1. 用户准备可用的 VLM 与 TypeSafe 账号/额度，把密钥放到约定运行环境，任务中只记录变量名或凭据位置。

- [ ] Agent 能在指定环境执行连接检查，权限由用户完成；不会因为已有账号就宣称 API 或设备能力已验收。
- [ ] 记录谁可以使用哪台设备、何时使用、相关版本和未满足条件；真实运行证据由后续任务负责。
- [ ] 完成上述准备后再解除模型兼容性任务阻塞。
