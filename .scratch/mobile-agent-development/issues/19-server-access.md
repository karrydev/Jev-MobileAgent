## 前置依赖

无其他实施任务依赖。领取仍须遵守共享文件和设备预约约定。

## 修改范围

仅登记服务器、域名/访问入口与凭据引用；不实施部署。超出范围先与对应负责人协调；根配置和契约不由消费者自行修改。

## 实施与产物

1. 用户提供或明确批准普通服务器、设备可访问的网络入口及必要账号；无需为外部模型 API 预购 GPU。
2. 登记部署负责人、配置注入方式、证据保留位置和回退入口，确认测试期间手机的网络条件。
3. 未提供服务器时记录人工阻塞，不将本机服务或 USB 转发当作最终环境。

## 验收

- [ ] 负责人能够在明确授权范围内访问部署环境，凭据不写进仓库。
- [ ] 手机预期的独立访问链路和测试窗口明确；真实连通与运行由部署验收任务验证。

## 证据与交接
