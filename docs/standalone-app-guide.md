# 手机独立使用说明（验收候选稿）

安装 Jev Mobile Agent，允许通知，并在系统无障碍设置中启用 Jev 服务。打开 App，填写 VLM 的 endpoint、model 和自己的 API Key，点击“保存 VLM”。GUI-Plus 可使用 `https://dashscope.aliyuncs.com/compatible-mode/v1` 和 `gui-plus`；已保存的 Key 不回显，留空保存时保留原值。开启 Jev 受控候选选择时，还需单独填写并保存 TypeSafe 配置。Key 在手机 Android Keystore 加密保存，不随 APK 提供。

输入任务目标，准备在目标应用中运行，通过通知开始，并立即收起通知栏，让目标应用保持前台。运行期间保持手机解锁和联网；模型通过手机直接请求供应商。通知栏提供暂停和取消入口，普通使用无需电脑、ADB、设备桥或自己的服务器。首次使用可先运行 App 内的受控中文输入和蓝框目标。

需要亲自操作手机时先暂停。断网、锁屏、权限丢失、进程重启或已检测的现场变化会停止自动执行；恢复网络、解锁、重新授权或重开 App 不会自动继续。回到任务页面，从通知点击“重新观察核对”，检查显示的动作事实与整体目标，再明确选择“确认恢复”或“结束任务”。确认前 App 会再次读取现场；页面或目标变化时需要重新核对。

动作回执不等于结果成功。记录为 UNKNOWN 的动作不会自动重放，可能需要检查实际结果；已发生的动作不会被暂停/取消撤销。已完成目标可以经新观察和明确确认结束，历史执行与用户确认分别记录。无法证明执行事实或效果时会保留缺口，不通过清空历史继续。

Jev选择、树核验、按需规划均为可选开关，默认关闭；开关在新任务创建时固定，不改变已有任务。规划关闭时采用原规划方式。具体支持的模型和预算以设置页为准；当前受审价格为GUI-Plus输入¥1.5/百万token、输出¥4.5/百万token。当前验收版本的 Jev 上限为每任务 5 次、累计 150 次，VLM 每任务最多 25 次，任务最多 5 步。单任务¥1、累计¥10是标价估算与未知预留门禁，实际供应商账单另查。Jev美元usage单独保存，未确认汇率前采用保守预留，不宣称已知实扣。提高调用次数上限不会重置用量，也不会提高金额上限。

更新时安装同签名新版APK，保留App数据、配置、任务记录和预算。不要卸载或清除数据来绕过暂停/未知动作或预算。供应商 Key 失效或“仅使用免费额度”耗尽时，需要在供应商账户处理，或选择已支持且有额度的模型。

已知边界：无障碍树不能读取所有自绘/WebView内容，截图也可能受窗口限制。普通无障碍服务无法保证收到每次原始手指触摸，接管前应使用明确暂停入口；现场变化门禁的实际覆盖以最终验收报告为准。当前整任务的独立自动完成判据仅覆盖约定的受控中文输入和蓝框目标；其他目标不能仅凭模型说“完成”就自动判定成功，可能需要人工核对并结束。当前仅有 OnePlus8T / Android14 的受控实测，不能据此保证任意应用、任意ROM或敏感操作的成功率。
