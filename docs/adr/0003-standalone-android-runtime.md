# 独立 Android App 承载任务编排并直连模型

2026-09-25：用户明确最终产品为安装 APK、在 App 输入模型 Key 后即可独立运行。以此替代 ADR-0001 的 Python 服务端编排：观察、候选、规划调度、动作、核验、任务状态与恢复均在 App 内完成，App 通过 HTTPS 直接调用配置的模型供应商；不要求用户提供服务器、设备桥地址、桥 Token、电脑或 ADB。独立运行仍需要模型网络服务，不包含离线大模型。

现有 Android 设备能力和已提取的角色行为、提示词、样例、评测判据继续复用；将必要 Python 编排行为移植到现有 Android 工程，不为复用而在 APK 内启动 Python HTTP 设备桥。Python 服务、部署脚本及 19/20 的记录保留为历史参考和开发对照，不是产品运行依赖或独立 App 已完成的证据。

ADR-0002 的单手机单任务、暂停、核对与显式恢复继续有效；双端连接恢复改为 App 生命周期、模型网络与本地动作记录的核对。先由任务 26 建立手机内仅 VLM 闭环，27 验证恢复与无电脑使用；21 验证已提供的 Jev 访问，22–25 在手机内逐步接入策略，28 对最终 APK 验收。此次调整不增加任务编号。
