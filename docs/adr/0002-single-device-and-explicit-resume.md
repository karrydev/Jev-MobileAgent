# 首版单手机单任务，异常后由用户确认恢复

2026-09-22 路线讨论已确认：首版面向单用户、单台手机，同一时间只执行一个任务。并行开发不意味着产品需要多设备调度；多设备、多用户和并发任务留到后续，协议设计可以保留身份字段，但不据此扩大首版交付范围。

断线、进程重启或用户手动操作打断任务后，系统先暂停，重新观察并核对命令回执和现场，再等待用户确认恢复。自动重连只恢复通信，不授予继续操作的权限；结果不明的动作不自动重放，证据仍不足时继续暂停并说明原因。

相对于自动续跑，这会增加一次用户操作，但能避免跨越连接中断或人工介入继续使用旧目标、重复产生副作用。两端需要保存足以核对执行历史的证据，持久化方式与协议字段在共享契约任务中确定。
